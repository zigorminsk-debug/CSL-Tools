🌐 Сетевые карты

ipconfig /all, Get-NetAdapter, netsh, psutil. IP, маска, шлюз, DHCP, скорость, статус UP/DOWN.

🔒 VPN / Прокси

Поиск TAP/TUN/WireGuard/OpenVPN/Nord. Проверка реестра ProxyEnable, ProxyServer, PAC, netsh winhttp.

📡 Пинг / Трассировка

Пинг 8.8.8.8, 1.1.1.1, google.com, csl.by. Трассировка tracert -d -h 20. Подсветка потерь.

🔍 DNS / DHCP / Интернет

DNS сервера, nslookup, резолв 4 доменов, проверка TCP 53 и HTTPS. DHCP enabled.

🛠 Исправление ошибок

flushdns, release/renew, winsock reset, int ip reset, advfirewall reset, отключение прокси, рестарт адаптера, полный сброс.

💀 BlueScreen

Чтение C:\Windows\Minidump, MEMORY.DMP, журнал BugCheck 1001/41, CrashControl. Вывод даты и причин.

📦 Что в архиве

Готовый релиз лежит в папке release/ и dist/:

  • CSL-Tools.exe — готовая программа (собрана на Linux, для нативной Windows сборки запустите build_exe.bat на Windows)
  • main.py — исходник, можно запускать напрямую: python main.py
  • build_exe.bat — двойной клик на Windows соберет настоящий Windows EXE
  • icon.ico / icon.png — иконка в стиле csl.by
  • README.md — документация

Для 100% Windows EXE: скопируйте папку на Windows ПК, установите Python 3.10+, запустите build_exe.bat от Администратора. Получите dist/CSL-Tools.exe 30 Мб.
