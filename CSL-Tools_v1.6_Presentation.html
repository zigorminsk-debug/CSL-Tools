📧 Отправка на admin@csl.by

Способ 1 — SMTP (автоматически):

  • Вкладка Отчет + Email → заполните Организацию/Телефон
  • ⚙ SMTP → сервер mail.csl.by порт 587, логин/пароль
  • Сохранить → Тест → 📧 Отправить на admin@csl.by
  • Файл прикрепляется автоматически

Способ 2 — Outlook / Почта (без SMTP):

  • 📨 Открыть в Outlook / Почте
  • Открывает Outlook COM с вложением, fallback mailto
  • Файл в temp_reports/ — прикрепите вручную если mailto

📦 Инсталляторы (3 варианта)

1. Inno Setup (профи):

  • CSL-Tools.iss — скрипт
  • Требует Inno Setup → iscc CSL-Tools.iss
  • Результат: installer_output/CSL-Tools-Setup-v1.6.0.exe
  • Мастер установки, ярлыки, деинсталляция, запись в реестр

2. Python Installer:

  • CSL-Tools-Installer.exe — self-extracting
  • Копирует в C:\Program Files\CSL-Tools\
  • Ярлыки Desktop + Start Menu, запрос данных клиента

3. PowerShell:

  • Install-CSLTools.ps1
  • Запуск от Админа: .\Install-CSLTools.ps1
