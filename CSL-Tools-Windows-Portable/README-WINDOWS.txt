CSL-Tools v1.6.0 - Портативная версия для Windows
ООО «Компьютерная безопасность» | csl.by | admin@csl.by

Запуск:
  Двойной клик по CSL-Tools.bat
  или CSL-Tools-Console.bat для консоли
  или Python\pythonw.exe CSL-Tools.launch.pyw

Не требует установки Python! Встроен Python 3.10.11 embed.

Отправка отчета:
  Вкладка Отчет + Email -> Заполните Организацию/Телефон
  -> Отправить на admin@csl.by

Требует Windows 7/10/11 x32/x64

Для создания ярлыка:
  Правый клик по CSL-Tools.bat -> Создать ярлык -> Переименовать в CSL-Tools
